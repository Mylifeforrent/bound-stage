存放产品原型产出。由 Stage 5/7（原型设计）产出。

> **定位与免责（必读）**：
> - 本目录当前产出为**单文件轻量级 HTML 原型**（`index.html`，浏览器直接打开即用，无构建、无外部运行时依赖），**不是**原计划的 `prototype_spec.md`，**不构成页面权威**，禁止将其当作 `prototype_spec` 引用。
> - 页面集合与 IA 权威仍是 [frontend_design_spec](../06_architecture_design/frontend_design_spec-v1.0.md) §2（P01–P25）。本原型的页面集、三大冻结结构（审批卡片九要素分区 / TestRun 详情分区顺序 / 执行发起三层顺序）与状态呈现均取自该规范 §2 / §5 / §6，**未新增页面、组件或状态**。
> - 因此 PRD §8.5 [GAP] **G6 不因本文件关闭**：按规范 §8，原型产出后须重跑 Stage 5/6 UX 一致性评审，并经 `docs/13_changes/change_log.md` 登记（评审为独立任务，不在本次产出范围内）。
> - 界面中所有人名、数据、哈希、金额均为**合成演示数据**，非真实业务事实；规范中未定的事项在原型内显式标注 `[TBD-BIZ]`（如定时 cron/时区）。
