## 1.2 全局交互壳层（v1.2 收编 · 工程约定）

> 来源：轻量级原型 [index.html](../05_prototype/index.html) v0.3 的布局重构（用户裁定采用）。**页面流（C1–C4）、页面集（25 页）、状态集（05 §2）与链路出场均不变**；本节只登记壳层与呈现层的交互模式，实现落在 `frontend/src/components/layout/`。frontend_design_spec §3「全局布局层」按此执行。

| # | 模式 | 约定 |
| --- | --- | --- |
| 1 | 侧栏树导航 | 一级导航 10 项 IA 不变（P18/P19 里程碑前隐藏）；项目 / 测试中心 / 门禁 / 管理后台四组在侧栏内**可展开树**，子项 = 路由树（项目 7 / 测试中心 3 / 门禁 2 / 管理 6）。子项注记保留：「执行」= P09 项目过滤视图（缺口 G1）、「环境」双入口同页。分组标签点击进入其落地页，箭头仅展开/收起；当前路由自动展开所在分组并点亮；1024–1279px 强制图标态（隐藏子树） |
| 2 | 面包屑 | 顶栏左侧「分组 › 页面」两级；无分组页（工作台 / 发布 / 审批 / 证据）只显示页面名。仅为定位辅助，不替代页内 PageHeader |
| 3 | 全局搜索 | 壳层顶栏搜索输入为**原型占位**：IA 未定义全局搜索承接页，回车提示不新增页面 `[TBD-UX]`（由 Prototype 评审裁定去留；删除不影响任何链路） |
| 4 | 工作台统计带 | P01 四区块（待审批 / 进行中 TestRun / 门禁异常 / 预算余量）上方加 4 枚汇总统计瓦片：仅为同一数据的计数呈现，点击**页内锚点滚动**到对应卡片，不新增跨页跳转（跳转矩阵 §4.1 不变） |
| 5 | 执行发起向导轨 | P08 三层自上而下顺序仍冻结（05 §4.3 约束 3）；向导节点随用户选择推进出现「完成态」标记，属呈现层增强，不改变校验时序（校验仍以服务端 VALIDATING 为准，C3 ④） |
| 6 | 证据呈现 | P09 证据查看器为深色查看面板（截图 / 视频 / Trace 三态切换不变，§6.6）；Trace 以瀑布条呈现 span 时长；截图占位用「浏览器窗框」样式标识证据脱敏位。呈现语义与各断点一致（§7） |

呈现层新增组件（NavTree / Breadcrumb / StatTile 等）按 [frontend_design_spec §8](../06_architecture_design/frontend_design_spec-v1.0.md) 评审纪律登记于 [change_log.md](../13_changes/change_log.md)；不携带业务语义，不新增 US / FR / AC / API / 状态。
